==== 3. Verify the application health endpoint ====

$ curl -sS -w \nHTTP %{http_code}\n http://localhost:8080/health
{"status":"ok"}
HTTP 200

$ docker inspect --format {{.Name}} health={{.State.Health.Status}} cs454-project1-app-1
/cs454-project1-app-1 health=healthy

==== 4. Perform two successful conversions ====

$ curl -sS -w \nHTTP %{http_code}\n http://localhost:8080/convert?lbs=150
{"lbs":150,"kg":68.039,"formula":"kg = lbs * 0.45359237"}
HTTP 200

$ curl -sS -w \nHTTP %{http_code}\n http://localhost:8080/convert?lbs=0.1
{"lbs":0.1,"kg":0.045,"formula":"kg = lbs * 0.45359237"}
HTTP 200

====    (an invalid request, which must not be counted) ====

$ curl -sS -w \nHTTP %{http_code}\n http://localhost:8080/convert?lbs=-5
{"error":"lbs must be a non-negative, finite number."}
HTTP 422
